ii# 🏆 cp (Competitive Programming Compilation)

> *A structured workspace for tracking progress, revisiting past approaches, and preparing for competitive programming events like ICPC 2025–26.*

## 🚀 About

This repository is my running record of competitive programming practice. It houses contest submissions and standalone problem solutions, consolidated in one place rather than scattered across various judges.

It exists primarily as a personal workbench to revisit old attempts, track the evolution of my problem-solving logic, and maintain a searchable trail of my work. **Note:** This is a live workspace, not a polished showcase. Expect rough drafts, first-pass solutions, and code optimized for the clock rather than readability.

## 🌟 Project Structure

```text
cp/
├── contest/
│   └── inception/     # Solutions from the "Inception" contest
├── problems/
│   ├── STL/           # Standard Template Library explorations
│   │   ├── a.cpp
│   │   └── test
│   └── greedy/        # Greedy algorithms (theory and practice)
│       ├── a.cpp
│       └── README.md
├── .gitignore
├── LICENSE            # MIT
└── README.md
```

### Contents

**`contest/inception/`**
Submissions written during the *Inception* contest — kept as-solved, including approach and edge cases as I reasoned through them at the time.

**`problems/`**
Solutions to individual problems worked through outside of contest settings — mostly used for drilling specific topics (data structures, number theory, graph algorithms) at my own pace.

This structure is intentionally simple and will grow as more contests and problem sets get added.

<br/>

### Stack

Written primarily in **C++**, using standard competitive-programming idioms — fast I/O, STL containers, and templated boilerplate for repeated patterns across problems.

<br/>

### Using this repo

```bash
git clone https://github.com/sinhasvnit/cp.git
cd cp
# compile a solution
g++ -O2 -std=c++17 path/to/solution.cpp -o solution
./solution
```
