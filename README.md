### About

This repository is my running record of competitive programming practice — contest submissions and standalone problem solutions, kept in one place instead of scattered across judges. It exists mainly for myself: to revisit old attempts, track how my approach to a problem changes over time, and keep a searchable trail of work as I prepare for ICPC 2025–26.

Nothing here is polished for an audience. It's a workbench, not a showcase — expect drafts, first-pass solutions, and code written under a clock rather than for readability.

<br/>

### Structure

```text
cp/
├── contest/
│   └── inception/     # Solutions from the "Inception" contest
├── problems/           # Standalone problem solutions
├── .gitignore
├── LICENSE             # MIT
└── README.md
```

<br/>

### Contents

**`contest/inception/`**
Submissions written during the *Inception* contest — kept as-solved, including approach and edge cases as I reasoned through them at the time.

**`problems/`**
Solutions to individual problems worked through outside of contest settings — mostly used for drilling specific topics (data structures, number theory, graph algorithms) at my own pace.

This structure is intentionally simple and will grow as more contests and problem sets get added.

<br/>

### Stack

Written primarily in **C++**, using standard competitive-programming idioms — fast I/O, STL containers, and templated boilerplate for repeated patterns across problems.

<br/>

### Using this repo

```bash
git clone https://github.com/sinhasvnit/cp.git
cd cp

# compile a solution
g++ -O2 -std=c++17 path/to/solution.cpp -o solution
./solution
```
